### Added (30)

- `documentdb.cleanupCursorFiles` (bool, default `true`) — Whether or not to clean up cursor files via cleanup worker.
- `documentdb.emitEnableOrderedIndexFalseInResponse` (bool, default `true`) — When enabled, list index responses include "enableOrderedIndex": false for indexes whose enableCompositeTerm was explicitly set to false (-1). When disabled, the field is omitted for those indexes.
- `documentdb.enableCommutativeUpdateMany` (bool, default `false`) — Whether to enable commutative writes for updateMany to improve performance. Can lead to deadlocks when concurrent writes update the same document.
- `documentdb.enableCompactVacuumFull` (bool, default `false`) — Whether to enable VACUUM FULL execution during compact command. When off, compact is a no-op.
- `documentdb.enableDeleteOnePlanCacheOptimization` (bool, default `true`) — Whether to enable optimized plan caching for delete-one operations.
- `documentdb.enableDistinctCustomScan` (bool, default `false`) — Whether or not to enable distinct custom scan.
- `documentdb.enableDistinctIndexPushdown` (bool, default `true`) — Whether to enable pushing down distinct operations to the index.
- `documentdb.enableDottedValueTextIndexTerms` (bool, default `true`) — Whether to enable generating index terms for dotted values (e.g. "foo.bar").
- `documentdb.enableGroupByDistinctScan` (bool, default `false`) — Whether or not to enable the distinct custom scan wrapper for $group pipelines that have no aggregate accumulators.
- `documentdb.enableIndexPathKeySummarization` (bool, default `true`) — Whether or not to enable summarization of index path keys.
- `documentdb.enableInsertDuplicateInlineHandling` (bool, default `true`) — Whether to enable inline handling of duplicate inserts.
- `documentdb.enableNonBlockingUniqueIndexBuild` (bool, default `true`) — Whether to enable non-blocking background builds of unique indexes.
- `documentdb.enableObjectIdFuncExprConversion` (bool, default `true`) — Whether to enable conversion of ObjectId function expressions.
- `documentdb.enablePullNestedArrayEqFix` (bool, default `true`) — Enables fix for $pull with $eq to correctly remove matching nested array elements.
- `documentdb.enableRumCursorDynamicIndexScans` (bool, default `true`) — Whether to enable dynamic index scans for RUM cursors.
- `documentdb.enableRumDynamicIndexScansSkipToTid` (bool, default `true`) — Whether to enable skipping to TID for dynamic index scans for RUM cursors.
- `documentdb.enableSampleScanFixOnSharded` (bool, default `true`) — Enables fix for $sample TABLESAMPLE on sharded collections.
- `documentdb.enableSortPushToAccumulatorWithPrefix` (bool, default `false`) — Whether to push suffix sort keys into accumulator when group keys are a prefix of sort keys in $sortGroup.
- `documentdb.enableStrictAddToSetModifierValidation` (bool, default `true`) — Reject $position/$slice/$sort (or any non-$each sibling) inside $addToSet, matching MongoDB behavior.
- `documentdb.indexBuildFailurePoint` (int, default `0`) — Inject a failure at a specific point during index background build or reindex post-processing. 0 = disabled, 1-9 = specific failure points.
- `documentdb_core.enableBsonSelectivityFromBtreeStats` (bool, default `false`) — Whether to enable selectivity calculations based on btree statistics for bson btree operators.
- `documentdb_rum.allow_replace_on_insert_tuple` (bool, default `true`) — Sets whether or not to allow replacing an existing tuple on insert
- `documentdb_rum.enable_btree_lock_order` (bool, default `true`) — Sets whether or not to enable using the btree lock order in rum index operations
- `documentdb_rum.enable_compare_function_fmgr` (bool, default `true`) — Sets whether or not to enable the use of the compare function in the fmgr
- `documentdb_rum.enable_custom_xlog_rmgr` (bool, default `false`) — Sets whether or not to enable the custom XLOG resource manager
- `documentdb_rum.enable_emit_reuse_page_on_recycle` (bool, default `false`) — Test GUC - emit a btree REUSE_PAGE WAL marker before reusing a vacuum-deleted RUM page from the FSM, so streaming standbys resolve recovery conflicts before the page contents are overwritten. Not ready for real consumption.
- `documentdb_rum.enable_overwrite_entry_tuple_on_vacuum` (bool, default `true`) — Sets whether or not to overwrite entry tuples during vacuum, as opposed to deleting and readding them
- `documentdb_rum.enable_targeted_posting_tree_pruning` (bool, default `false`) — Enables targeted pruning of empty posting tree pages during vacuum
- `documentdb_rum.enable_xlog_insert_entry` (bool, default `false`) — Sets whether or not to enable XLOG insert entry
- `documentdb_rum.inject_split_entry_internal_only` (bool, default `false`) — Test GUC - only inject split failure on entry internal page splits (when childbuf is valid)
